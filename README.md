# 사이드 메모

화면 가장자리에서 나오는 탭형 스티커 메모 (Windows / Electron).

## 받기

그냥 쓰고 싶다면 [Releases](../../releases) 에서 `SideMemo-Setup-*.exe` 를 받아 실행하세요.
클릭 한 번으로 설치되고 바로 실행됩니다. 윈도우 10/11 64비트용입니다.

> 설치할 때 "알 수 없는 게시자" 경고가 뜹니다. 코드 서명 인증서를 붙이지 않아서이며,
> `추가 정보` → `실행`으로 진행하면 됩니다.

아래는 소스에서 직접 돌리거나 고치려는 분을 위한 내용입니다.

## 실행

```bash
npm install
```

```bash
npm start
```

개발용(렌더러 콘솔 로그 + 여닫힘 로그 표시):

```bash
npm run dev
```

`--open-settings` 를 함께 주면 실행하자마자 패널과 설정 화면을 펼칩니다. (`npm run dev -- --open-settings`)
`--open` 은 패널만 펼칩니다.

기능 점검:

```bash
npm test
```

주고받기 24가지와 저장소 19가지(단위 테스트), 그리고 임시 프로필에서 앱을 띄워 실제 UI를 조작하는 100가지를 확인합니다. **실제 메모는 건드리지 않습니다**
(`--user-data-dir` 를 주면 앱이 그 폴더를 쓰고, 임시 프로필이 아니면 테스트가 즉시 중단됩니다).

## 기능 안내는 앱 안에 있습니다

설정(⚙) 맨 위의 **"이 프로그램으로 할 수 있는 것"** 을 펼치면 전체 기능이 한 장에 정리돼 있습니다.
단축키는 **지금 설정된 값**이 그대로 표시되므로, 바꿔 쓰더라도 안내와 어긋나지 않습니다.

## 쓰는 법

- 화면 가장자리의 **탭 제목에 마우스를 올리면** 그 메모지가 미끄러져 나옵니다.
  탭이 아닌 곳(빈 자리, ＋ 버튼)에서는 나오지 않고, 다른 탭으로 옮기면 그 메모로 바뀝니다.
- 마우스가 메모지를 벗어나면 바로 접힙니다. 계속 띄워두려면 헤더의 **📌** 을 누르세요.
- 탭을 클릭하면 메모가 바뀌고, 열린 탭을 다시 누르면 접힙니다.
- 탭 **우클릭** → 휴지통으로, 탭 아래 **＋** → 새 메모.
- 탭을 **위아래로 끌면 그 탭만 움직입니다.** 하나만 화면 맨 아래에 두는 식으로 자유롭게 배치할 수 있습니다.
  다른 탭 가까이 가져가면 **딱 붙습니다.** (5px 이상 움직여야 드래그로 봅니다)
- **더블클릭하면 고정**됩니다. 탭 · 메모 본문 · 제목 표시줄 아무 데나 됩니다. 다시 더블클릭하면 해제됩니다.
- 헤더의 **🔍** 또는 `Ctrl+F` → 모든 가장자리의 모든 메모에서 찾기.
- 접혀 있는 동안에는 탭 위를 뺀 나머지 영역의 클릭이 아래 창으로 그대로 통과합니다.
- 트레이 아이콘: 좌클릭 열기/닫기, 우클릭 메뉴(가장자리 좌/우, 모니터, 고정, 시작 시 실행, 종료).

### 단축키

윈도우 어디서나(다른 프로그램을 쓰는 중에도) 동작하는 전역 단축키입니다. 설정에서 바꿀 수 있습니다.

| 기능 | 기본값 | 설명 |
|---|---|---|
| 메모 열기 / 닫기 | `Ctrl + Alt + M` | 지금 상태의 반대로. 접혀 있으면 펼치고, 펼쳐져 있으면 접습니다. |
| 새 메모 추가 | `Ctrl + Alt + N` | 패널을 펼치고 새 탭을 만든 뒤 이름 입력란에 커서를 둡니다. |
| 다음 메모로 | `Ctrl + Alt + →` | 탭을 순서대로 넘깁니다. 마지막 다음은 처음으로. |
| 잠시 숨기기 / 다시 보이기 | `Ctrl + Alt + H` | 화면에서 통째로 감췄다가 되돌립니다. |

설정에서 `사용` 체크를 끄면 전역 단축키를 아예 등록하지 않습니다. 개별 항목만 끄려면 그 줄의 `✕` 를 누르세요.
가장자리가 여러 개일 때는 **마지막으로 쓴 메모지**를 대상으로 동작합니다.

바꾸려면 설정의 단축키 버튼을 누르고 원하는 조합을 누르세요. `Esc` 로 취소합니다.
다른 프로그램이 이미 쓰는 조합은 등록되지 않고 이전 값으로 되돌아갑니다.
(`Ctrl+Alt+Space` 는 한글 입력기가 선점하는 경우가 많아 기본값에서 뺐습니다.)

패널 안에서만 쓰는 키: `Esc` 닫기, `Ctrl+S` 즉시 저장, `F5` 날짜/시간 넣기, 링크 `Ctrl+클릭` 으로 브라우저에서 열기.

앱에는 메뉴 막대가 없고 기본 메뉴도 꺼두었습니다. `Ctrl+R`·`F5` 가 새로고침으로 먹혀
편집 중인 메모가 날아가는 일을 막기 위해서입니다.

### 서식

굵게 · 기울임 · 밑줄 · 취소선 · 정렬 · 글머리 기호 / 번호 매기기 · 글자색.
`http://`로 시작하는 주소를 치고 공백이나 엔터를 누르면 링크가 됩니다. `Ctrl+클릭`으로 기본 브라우저에서 열립니다.

### 날짜 · 시간 넣기

메모장(notepad)처럼 **`F5`** 를 누르면 커서 자리에 지금 시각이 들어갑니다.

| 키 | 들어가는 글자 |
|---|---|
| `F5` | `2026-08-19 (수) 오전 10:04` |
| `Shift + F5` | `2026-08-19 (수)` |
| `Ctrl + F5` | `오전 10:04` |

메모지가 접혀 있으면 펼치면서 넣고, 설정·검색 화면이 열려 있을 때는 동작하지 않습니다.

### 이미지

툴바의 🖼 버튼, 드래그 앤 드롭, 붙여넣기 모두 됩니다. **장수 제한 없습니다.**
이미지를 클릭하면 오른쪽 아래에 **크기 조절 손잡이**가 붙습니다. 잡고 끌면 바로 크기가 바뀝니다.
같이 뜨는 팝오버에는 슬라이더(5~100%)와 25/50/75/100% 버튼, 삭제 버튼이 있습니다.

### 파일 첨부

툴바의 📎 버튼, 또는 파일을 메모지 위로 **끌어다 놓기**(붙여넣기도 됩니다).
이미지가 아닌 파일은 이름과 크기가 적힌 칩으로 들어갑니다.

- **클릭** → 기본 프로그램으로 열기
- **우클릭** → 탐색기에서 저장 위치 보기
- 칩을 지우면(백스페이스) 첨부도 함께 정리됩니다

파일은 `%APPDATA%\side-memo\files\` 로 **복사**됩니다. 원본을 옮기거나 지워도 메모에서는 계속 열립니다.
`.exe` `.bat` `.ps1` 처럼 실행되는 파일은 클릭 한 번에 실행되지 않도록 한 번 더 확인합니다.

### 꾸미기

설정(⚙)에서 배경색·글자색(견본 + 직접 선택), 폰트, 글자 크기, **투명도**, 패널 폭, 붙는 위치를 바꿉니다.

**폭 조절** 세 가지 방법:

1. **메모지의 안쪽 모서리를 잡고 끌기** — 설정에 들어갈 필요 없이, 끈 폭이 **그 메모에만** 적용됩니다.
   ('이 메모만'이 자동으로 켜집니다. 더블클릭하면 380px로.)
2. 설정의 숫자 칸에 직접 입력하거나 `−` `＋` 로 10px씩.
3. 설정의 슬라이더 — 끄는 동안은 숫자만 바뀌고 **손을 뗄 때 적용**됩니다.

### 메모마다 다른 크기

글자 크기와 패널 폭 옆의 **'이 메모만'** 을 켜면 그 메모에만 적용되는 값이 됩니다.
끄면 전체 기본값을 다시 따라갑니다. 탭을 옮길 때마다 그 메모의 크기로 자동 전환됩니다.
(예: TODO는 좁고 작게, WORK는 넓고 크게)

설정 화면의 슬라이더는 '이 메모만'이 꺼져 있으면 **전체 기본값**을, 켜져 있으면 그 메모만 바꿉니다.
모서리 드래그는 언제나 그 메모만 바꿉니다.

### 가장자리 여러 개 쓰기

가장자리 하나 = 창 하나 = **완전히 별개의 메모 묶음**입니다.
설정의 `＋ 가장자리 추가` 로 늘리고, 각 줄의 `삭제` 로 줄입니다.

- 한 모니터에 좌·우 2개, **모니터 2대면 최대 4개**
- 같은 (모니터, 좌/우) 자리에는 하나만 붙을 수 있습니다
- 색·폰트·투명도 같은 겉모습은 **전체 공통**, 폭과 글자 크기는 메모별로 따로 둘 수 있습니다
- 마지막 하나는 지울 수 없습니다

### 탭 위치

설정의 **탭 자유 배치** 로 두 가지 방식 중에 고릅니다.

**켬 (기본)** — 탭을 하나씩 끌어서 원하는 높이에 둡니다.

- 끌어 놓은 탭은 그 자리에 고정됩니다 (화면 높이 대비 **비율로 저장**되어 해상도가 달라도 같은 자리)
- 다른 탭에서 12px 안으로 들어가면 **딱 붙습니다.** 화면 위·아래 끝에도 붙습니다
- 다른 탭 위로 끌면 **그 탭이 위/아래로 비켜납니다.** 서로 겹치지 않습니다
- 건드리지 않은 탭은 계속 자동으로 쌓입니다. 그 시작 높이는 **탭 세로 위치** 슬라이더로 조절합니다
- **탭 위치 초기화** 를 누르면 전부 자동 배치로 돌아갑니다

**끔** — 항상 위에서부터 차곡차곡 정렬됩니다. 끌면 **순서만** 바뀌고 위치는 자동으로 정리됩니다.

어느 쪽이든 **끄는 동안 결과가 그대로 보입니다.**
놓일 자리에 점선 표시가 뜨고, 비켜나는 이웃 탭들이 실시간으로 움직입니다.
＋ 버튼도 항상 탭과 겹치지 않는 자리로 따라갑니다.

### 화면에서 숨기기

메모지가 늘 보이는 게 부담스러울 때 두 가지 방법이 있습니다.

**1. 탭 보이기 모드** (설정)

| | 동작 |
|---|---|
| 항상 보이기 (기본) | 지금까지처럼 탭이 늘 붙어 있습니다 |
| **가장자리에 마우스를 댈 때만** | 평소엔 탭이 안 보이다가, 화면 끝에 커서를 대면 스르륵 나타납니다 |
| 숨기기 | 아예 안 보입니다. 단축키나 트레이 아이콘으로만 엽니다 |

숨어 있는 동안에는 **클릭도 통과**하므로 아래 창을 쓰는 데 지장이 없습니다.
어느 모드든 메모지를 펼치면 탭이 함께 보여서 다른 메모로 옮길 수 있습니다.

**2. 잠시 숨기기** — 화면 공유나 발표처럼 잠깐 치워야 할 때.

- 트레이 우클릭 → **잠시 숨기기**
- 설정의 **지금 잠시 숨기기** 버튼
- 단축키 **`Ctrl + Alt + H`**

창을 통째로 감춥니다. 같은 단축키를 다시 누르거나 트레이 메뉴를 끄면 돌아옵니다.
**열기 단축키(`Ctrl+Alt+M`)를 누르면 숨김이 자동으로 풀리면서** 메모가 나옵니다 — 숨겨둔 걸 잊어도 빠져나올 수 있습니다.

### 모니터 / 접히는 방식

- **붙는 모니터**: 설정의 드롭다운. 모니터를 뽑으면 자동으로 주 모니터로 돌아갑니다.
- **언제 접을까요**:
  - `마우스가 벗어나면 바로` (기본) — 커서가 메모지 밖으로 나가면 접습니다. 메모를 클릭해 편집 중일 때는 유지됩니다.
  - `다른 창을 클릭하면` — 커서가 나가도 열려 있고, 다른 창으로 포커스가 넘어갈 때 접습니다.
  - `직접 닫을 때만` — ✕ · `Esc` · 탭 클릭 · 단축키로만 접힙니다.
- **📌 고정**을 켜두면 어떤 모드에서도 접히지 않습니다.
- **닫히는 속도**: 마우스가 벗어난 뒤 접히기까지의 여유입니다.

  | | 유예 | 슬라이드 |
  |---|---|---|
  | 즉시 | 0ms | 100ms |
  | 빠르게 (기본) | 110ms | 140ms |
  | 느긋하게 | 320ms | 190ms |

  커서 위치는 **40ms마다** 확인하므로 어느 쪽이든 반응이 즉각적입니다.

### 고정하기

**아무 데나 더블클릭**하면 됩니다 — 탭 / 메모 본문 / 제목 표시줄. 헤더의 **📌** 버튼도 그대로 있습니다.
해제도 같은 자리를 다시 더블클릭하면 됩니다.

본문은 **글자 위든 아래 빈 곳이든 어디를 더블클릭해도** 고정됩니다.
이미지·첨부파일·링크 위는 각자 동작이 있어 제외됩니다.
(본문에서 단어를 고르려고 더블클릭하면 고정도 함께 토글되니 참고하세요.)

고정되면 한눈에 보이도록 세 군데가 바뀝니다.

- 메모지 테두리에 **보라색 링**이 생깁니다
- 제목 아래 **📌 고정됨** 배지가 붙습니다
- 가장자리의 **탭에도 같은 링**이 생겨서, 접혀 있어도 고정 상태를 알 수 있습니다

바꾼 직후에는 안내 문구가 잠깐 떴다 사라집니다.
고정은 앱을 껐다 켜면 풀립니다(부팅 후 메모지가 계속 열려 있는 게 더 당황스러워서 이렇게 뒀습니다).

## 메모 주고받기

설정의 **메모 주고받기** 에서 `이 메모 내보내기…` / `전체 내보내기…` / `메모 가져오기…` 를 씁니다.

| 형식 | 쓰임 |
|---|---|
| **`.smemo`** | 사이드 메모를 쓰는 사람에게. **이미지·첨부파일까지 파일 하나에** 담기므로 그 파일만 건네면 됩니다. 받은 사람은 `메모 가져오기…` 로 새 메모로 추가합니다. |
| **`.html`** | 앱이 없는 사람에게. 브라우저로 바로 열립니다. 이미지는 파일 안에 박혀 들어가고, 첨부파일은 이름만 남습니다. |
| **`.txt`** | 서식 없이 글자만. |

`.txt` 와 `.md` 는 **가져오기**도 됩니다. 한 줄이 한 줄로 들어옵니다.

받아온 메모의 이미지·첨부파일은 **받는 사람 PC로 복사**되고 새 이름이 붙습니다.
보낸 사람 쪽 파일과 얽히지 않으므로, 지우거나 고쳐도 서로 영향이 없습니다.

> 여러 사람이 **같은 메모를 동시에 편집**하는 기능은 아직 없습니다.
> 저장 위치를 공유 폴더로 바꿔서 함께 쓰는 것은 **하지 마세요** — 메모 전체가 파일 하나라
> 나중에 저장한 쪽이 상대 메모를 덮어씁니다. (한 사람이 PC 두 대를 번갈아 쓰는 건 괜찮습니다.)

## 휴지통 · 백업 · 저장 위치

- **휴지통**: 지운 메모는 바로 사라지지 않고 설정 → 휴지통에 **30일** 보관됩니다. `되돌리기` 를 누르면 원래 있던 가장자리로 돌아갑니다. 휴지통에 있는 메모의 이미지·첨부파일도 함께 보존됩니다.
- **자동 백업**: 실행할 때 한 번, 이후 설정한 주기(기본 6시간)마다 `backups\data-YYYYMMDD-HHMMSS.json` 을 남기고 **최근 12개**를 보관합니다. `지금 백업` 버튼도 있습니다.
- **저장 위치**: 설정에 현재 경로와 기본 경로가 함께 표시됩니다. `위치 변경…` 으로 OneDrive 같은 폴더를 고르면 메모·이미지·첨부·백업을 **통째로 옮깁니다**(복사가 끝난 뒤에만 원본을 지웁니다). 고른 폴더에 이미 메모가 있으면 *그쪽 것을 쓸지 / 지금 것으로 덮어쓸지* 물어봅니다.

## 저장

`%APPDATA%\side-memo\data.json` 한 파일에 모든 메모와 설정이 들어갑니다.
입력이 멈추고 0.4초 뒤 자동 저장되며, 임시 파일에 쓴 뒤 교체하므로 저장 중 종료돼도 파일이 깨지지 않습니다.
이미지는 `%APPDATA%\side-memo\images\`, 첨부파일은 `%APPDATA%\side-memo\files\` 에 복사되고,
어느 메모에서도 참조하지 않는 파일은 정리됩니다.
예전 이름(`peekpad`)으로 저장된 메모가 있으면 첫 실행 때 자동으로 옮겨옵니다.

### 데이터가 깨졌을 때

`data.json` 을 읽지 못하면 앱은 **조용히 빈 상태로 시작하지 않습니다.**

1. 깨진 파일을 `data.json.broken-<시각>` 으로 남깁니다 (지우지 않습니다).
2. 가장 최근 백업부터 차례로 읽어보고, 읽히는 것으로 되살립니다.
3. 되살릴 백업이 하나도 없으면 빈 상태로 시작하되 **이미지와 첨부파일은 하나도 지우지 않습니다.**
   (참조가 사라졌다고 정리해버리면 되돌릴 수 없기 때문입니다.)

어느 쪽이든 시작할 때 무슨 일이 있었는지 알려줍니다.

창은 가장자리에 붙은 채 움직이지 않고, 안쪽 패널만 CSS `transform`으로 미끄러집니다.
접혀 있을 때는 `setIgnoreMouseEvents(true, { forward: true })`로 클릭을 통과시키고,
커서가 탭 띠 위로 오면 그때만 클릭을 받습니다.

폭을 드래그하는 동안에는 창을 **최대 폭으로 넓혀두고 패널만 CSS 로 줄입니다.**
창을 매 프레임 리사이즈하면 폭을 줄일 때 커서가 창 밖으로 빠져나가 드래그가 끊깁니다.
같은 이유로 설정 화면의 폭 슬라이더는 **놓을 때만** 적용합니다. 실시간으로 창을 줄이면
슬라이더 자체가 커서 밑에서 움직여 미세 조절이 불가능해집니다.

확인 창(`삭제할까요?` 등)은 **패널 안에 직접 그립니다.**
브라우저의 `confirm()`·`alert()` 를 쓰면 창이 포커스를 잃고, 그러면 `blur` → 자동 접힘이 일어나
열어둔 설정 화면까지 닫혀버립니다. 같은 이유로 파일·폴더 선택 창이 떠 있는 동안에도 자동 접힘을 멈춥니다.

커서가 창을 벗어났는지, 그리고 화면 가장자리에 닿았는지는 **메인 프로세스가 40ms마다 직접 확인**합니다.
창이 클릭을 통과시키는 동안에는 커서가 창 밖으로 나가는 순간 렌더러의 마우스 이벤트가 끊기기 때문에,
'가장자리에 마우스를 댈 때만' 모드는 렌더러만으로는 다시 숨길 수가 없습니다.
렌더러의 `mouseleave` 는 호버로 열렸을 때(창이 포커스를 받지 않은 상태)나 다른 창이 위로 올라올 때 놓치는 경우가 있어서입니다.

- 붙여넣기는 서식 없는 텍스트로 들어갑니다. 외부 HTML을 그대로 삽입하지 않기 위한 선택입니다.

## 새 버전 내보내기

`package.json` 의 버전을 올리고 태그를 밀면 **GitHub 가 알아서 빌드해서 릴리스에 붙입니다.**
직접 빌드하거나 파일을 끌어다 올릴 필요가 없습니다.

```bash
npm version 0.4.4 --no-git-tag-version
```

```bash
git add . && git commit -m "0.4.4" && git push
```

```bash
git tag v0.4.4 && git push origin v0.4.4
```

진행 상황은 저장소의 **Actions** 탭에서 볼 수 있고, 5~10분 뒤 Releases 에 설치본이 올라옵니다.

태그와 `package.json` 의 버전이 다르면 빌드가 **일부러 실패합니다.**
버전이 안 맞는 설치본이 나가는 걸 막기 위해서입니다.

> UI 테스트(`smoke-test`)는 실제 창을 띄우기 때문에 CI 에서는 돌리지 않습니다.
> 자동화가 확인하는 것은 순수 로직 테스트(주고받기 · 저장 복구)뿐이므로,
> 태그를 밀기 전에 손에서 `npm test` 를 한 번 돌려 주세요.
