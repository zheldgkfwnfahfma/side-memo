설정
이 프로그램으로 할 수 있는 것

열고 닫기

  • 가장자리의 탭 제목에 마우스를 올리면 메모지가 나옵니다.
  • 마우스가 벗어나면 접힙니다. 아무 데나 더블클릭하면 고정돼서 안 접힙니다.
  • 고정되면 보라색 테두리와 📌 고정됨 배지가 보입니다.
  • 접혀 있는 동안에는 탭을 뺀 나머지 영역의 클릭이 아래 창으로 통과합니다.

메모 관리

  • 탭 아래 ＋ 로 새 메모, 제목을 눌러 이름 변경, 왼쪽 아래 알약을 눌러 탭 색 변경.
  • 탭 우클릭 → 휴지통으로. 설정의 휴지통에서 30일 안에 되돌리기 가능합니다.
  • 탭을 위아래로 끌면 그 탭만 원하는 높이로 옮겨집니다. 가까이 가면 딱 붙습니다.

글쓰기

  • 굵게 · 기울임 · 밑줄 · 취소선 · 정렬 · 목록 · 글자색.
  • F5 로 지금 날짜와 시간을 넣습니다. Shift+F5 날짜만, Ctrl+F5 시간만.
  • http:// 주소를 치고 공백을 누르면 링크가 됩니다. Ctrl+클릭으로 열기.
  • 이미지: 🖼 버튼 · 끌어다 놓기 · 붙여넣기. 장수 제한 없음. 클릭하면 크기 조절 손잡이가 나옵니다.
  • 파일 첨부: 📎 버튼이나 끌어다 놓기. 칩을 클릭하면 열리고, 우클릭하면 저장 위치가 열립니다.

찾기

  • 헤더의 🔍 또는 Ctrl+F — 모든 가장자리의 모든 메모를 한 번에 찾습니다.

화면 배치

  • 메모지 안쪽 모서리를 끌면 폭이 바뀝니다 (그 메모에만 적용).
  • 글자 크기·폭은 '이 메모만' 을 켜서 메모별로 다르게 둘 수 있습니다.
  • 가장자리 추가로 화면 좌·우에 각각, 모니터 2대면 최대 4개까지.
  • 탭 보이기 를 바꾸면 평소엔 숨기고 가장자리에 마우스를 댈 때만 나오게 할 수 있습니다.
  • 발표 중엔 잠시 숨기기(Ctrl+Alt+H)로 통째로 감춥니다.

안전장치

  • 입력이 멈추면 0.4초 뒤 자동 저장. 따로 저장할 필요가 없습니다.
  • 지운 메모는 휴지통에 30일, 데이터는 주기적으로 자동 백업됩니다.
  • 저장 위치를 OneDrive 같은 폴더로 옮기면 다른 PC와 같은 메모를 볼 수 있습니다.

주고받기

  • .smemo 로 내보내면 이미지·첨부까지 파일 하나에 담깁니다. 받는 사람은 가져오기만 하면 됩니다.
  • 앱이 없는 사람에게는 .html 로 내보내면 브라우저에서 바로 보입니다.
